# 🚀 Laika The Spacecat! <3 🐱✨

An interactive retro-pixel space game website made with love by **Rakhel** for **Laika (My Space Cat)** to celebrate their **5th Monthiversary**.

---

## 🎮 Features Included:
1. **🚀 Space Exploration Game:**
   - Fly a rocket across the stars with Captain Laika (our cute astronaut cat!).
   - Smooth controls for both **Desktop Keyboard (WASD / Arrows / Space)** and **Mobile Phones (Virtual D-Pad & Touch Direct)**.
2. **🪐 5 Memory Planets (Months 1 through 5):**
   - Each planet marks a milestone of the 5-month journey together.
   - Features retro polaroid photo frames, sweet quotes, and collectible memory stars.
3. **🎉 Special Viral POV Banner Scene (I Love You):**
   - Recreates the iconic pixel art cardboard sign tribute:
     > **"I LOVE U LAIKA, MY SPACE CAT!"** 💖
     with floating pixel clouds and celebratory starlight confetti!
4. **🐟 Mini-Game: "Laika's Cosmic Treat Catcher":**
   - Catch cosmic fish, tuna cans, and love stars while dodging comets.
5. **💌 "Open When" Letters Station:**
   - 6 interactive paw-stamped envelopes to open whenever she feels like it (*Open on 5th Mensive, Open when you miss me, Open when you can't sleep*, etc.).
6. **🎵 8-Bit Chiptune Music & Retro SFX:**
   - Soft cozy 8-bit melody and sound effects synthesized directly using the Web Audio API (no external MP3 downloads required!).
7. **🐾 Secret Easter Egg ("Meowter Station"):**
   - A hidden celestial station at coordinates (X:1550, Y:350) with a special secret message and infinite love gauge!
